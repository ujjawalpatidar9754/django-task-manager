# Django Task Manager (CRUD Application)

A fully functional Task Manager web application built using Python and Django. It implements complete **CRUD (Create, Read, Update, Delete)** operations with a clean user interface.

## Features
- **Create**: Add new tasks with title, description, and completion status.
- **Read**: View the list of all created tasks.
- **Update**: Edit and update existing task details.
- **Delete**: Remove tasks that are no longer needed.
- **MVT Architecture**: Built following Django's Model-View-Template design pattern.

## Tech Stack
- **Backend**: Python, Django
- **Frontend**: HTML5, CSS3, Bootstrap 5
- **Database**: SQLite
